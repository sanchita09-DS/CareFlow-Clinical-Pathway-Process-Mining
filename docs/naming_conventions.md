# CareFlow Naming Conventions

## General Rules

- Use lowercase for file names.
- Use underscores (_) between words.
- Do not use spaces in file names.
- Use descriptive names.
- Avoid names like final.py, new.py, test2.py.

## Examples

### Correct
- event_log.csv
- data_cleaning.py
- patient_events.sql
- activity_mapping.csv

### Incorrect
- Final.py
- newfile.py
- test 2.py
- mydata.csv
